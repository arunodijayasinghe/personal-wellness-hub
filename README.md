# Personal Wellness Hub
A web application to track daily wellness activities such as exercise, sleep, water, meditation and mood.

## Tech Stack
Node.js, Express, MySQL, HTML/CSS/JavaScript

## Progress
- Day 1: Database schema, Express server, DB connection, Create feature
- Day 2: Read feature (list, details, search, filter, sort)
- Day 2: Update and Delete features
- Day 3: Client and server validation, error handling
- Day  4 and 5: UI and responsiveness, dashboard, wellness insights, tips, weekly report chart
